## 1. Project Overview

The **Lung Capacity Prediction System** is a machine learning-powered web application developed using Python and Streamlit. It applies a trained regression model to estimate lung capacity based on selected demographic and lifestyle characteristics.

The application provides an interactive interface through which users can enter individual characteristics, generate model-based predictions, review patient input profiles, and download prediction reports.

This project demonstrates the practical application of machine learning, predictive modeling, and interactive data science solutions within the health domain.

It was developed by **DataQuest Solutions** as part of its commitment to applying data science, artificial intelligence, and technology to real-world challenges.

## 2. Project Objectives

The main objectives are to:

- Demonstrate the application of machine learning in health data science.
- Develop an interactive web-based predictive modeling application.
- Apply a trained regression model to estimate lung capacity.
- Demonstrate how demographic and lifestyle characteristics can be incorporated into predictive models.
- Provide a user-friendly interface for generating and reviewing predictions.
- Demonstrate the integration of Python, Streamlit, and Scikit-learn in an end-to-end machine learning application.

## 3. Application Features

### Interactive Prediction Interface
Users can enter individual characteristics through an intuitive web interface.

### Model-Based Prediction
The application uses a previously trained regression model to generate lung capacity estimates.

### Patient Profile Summary
Displays the characteristics entered by the user, including age, height, gender, smoking status, and Caesarean birth history.

### Prediction Results
Presents the estimated lung capacity generated by the machine learning model.

### Downloadable Reports
Allows users to download prediction information in CSV format for documentation and further analysis.

## 4. Predictive Model Inputs

The application currently uses the following input variables:

| Variable | Description | Input |
|---|---|---|
| Age | Age of the individual | 3–25 years |
| Height | Individual's height | 40–80 inches |
| Smoke | Smoking status | Yes / No |
| Gender | Gender category | Female / Male |
| Caesarean | Caesarean birth history | Yes / No |

Categorical variables are encoded numerically before being passed to the trained model.

**Model input encoding:**

| Variable | Encoding |
|---|---|
| Gender | Female = 0, Male = 1 |
| Smoke | No = 0, Yes = 1 |
| Caesarean | No = 0, Yes = 1 |

The application preserves the feature names and ordering expected by the trained model.

## 7. Installation and Setup

### Prerequisites

Ensure that you have the following installed:

- Python 3.10 or later.
- pip (Python package manager).
- Git.
- A code editor such as Visual Studio Code.

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR-GITHUB-USERNAME/lung-capacity-prediction-system.git
```

Navigate into the project directory:

```bash
cd lung-capacity-prediction-system
```

### Step 2: Create a Virtual Environment

On Windows:

```powershell
python -m venv venv
```

Activate the environment:


On Linux or macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

```bash

```

### Step 4: Run the Application


The application will open in your default browser.

By default, Streamlit runs locally at:

```text
http://localhost:8501
```

**Important:** Ensure that `Best_Regression_Model.joblib` is available in the project directory before running the application.

## 8. Model Integration

The application loads a pre-trained regression model using Joblib.

The model is loaded through:

```python
from joblib import load
from pathlib import Path

@st.cache_resource
def load_prediction_model():
    model_path = (
        Path(__file__).resolve().parent /
        "Best_Regression_Model.joblib"
    )
    return load(model_path)
```

Predictions are generated using:

```python
prediction_value = float(model.predict(input_data)[0])
```

The model receives a structured input DataFrame containing the required features.

**Note:** The model training procedure, training dataset, model selection criteria, hyperparameter optimization, and validation performance should be documented separately when those details are made available. This repository should not be interpreted as evidence of clinical validation.

## 11. Limitations and Clinical Disclaimer

This application generates machine learning-based estimates for educational, research, and demonstration purposes.

It is **not a medical diagnostic tool** and must not be used as a substitute for:

- Clinical spirometry.
- Professional respiratory assessment.
- Medical diagnosis.
- Established clinical reference standards.

Predictions are dependent on the characteristics of the model's training data, feature definitions, preprocessing procedures, and model performance.

The model's clinical applicability has not been established by this application alone. Independent validation using appropriate clinical datasets and standards would be necessary before considering any clinical application.

Users should not make medical decisions based on the predictions generated by this system.
